# Guess The Number Game

A fun and interactive number guessing game that you can play in the cloud! Built with HTML, CSS, and JavaScript, this web-based game challenges you to guess a randomly generated number between 0 and 100 in just 10 attempts.

## What You Can Do in the Cloud

This game is designed to run in the cloud as a web application, allowing you to:

- **Play Anywhere**: Access the game from any device with a web browser
- **Share with Friends**: Simply share the URL to let others play
- **No Installation Required**: Start playing instantly without downloading anything
- **Always Available**: The game is hosted online and accessible 24/7

## Game Features

- Guess a number between 0 and 100
- Get 10 chances to find the correct number
- Receive hints after each guess (too high or too low)
- Personalized greetings based on the time of day
- Track your attempts and try to beat your best score
- Play again instantly with the click of a button

## How to Play

1. Open the game in your web browser
2. Enter your name when prompted
3. Start guessing numbers between 0 and 100
4. Use the feedback to narrow down your guesses
5. Try to guess the correct number in as few attempts as possible!

## Technology

- **HTML5** - Structure
- **CSS3** - Styling
- **JavaScript** - Game logic and interactivity

Enjoy playing in the cloud! 🎮
